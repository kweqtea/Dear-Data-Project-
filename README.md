# Dear-Data-Project-
Data Collection of my osu! Performance
I will be logging my data on my osu! plays for the next couple of weeks. Using Processing I will show this data visually in a pretty cool way that is inspired by the osu! skin that I use.
The primary focus of this project is to log my mood before and after a play, and how it fluctuates in the coming weeks.
Art credit: The character artwork in the background is from the Aira × Off Script osu! skin and is used for decoration only. It is not my own artwork.

Structure (may update things)
What each record holds: one row per play, with date, time, stars, map type, mods, rank, accuracy, misses, duration, song, and mood before and after.
How to run it: open DearData100/DearData100.pde in Processing and press Run. Hover over or click a circle to see a play’s details, and press "s" to save a PNG.
               Also please refrain from spamming "s", the PNGs will save in the screenshots folder.
Where the data lives: DearData100/data/plays.csv.
Progress: 2 plays logged so far, I will update this as i go.
          Additionally i will take a screenshot to show what my data looks like each day! (hopefully i can think of some cool things to add later on too)
